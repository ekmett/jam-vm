# jam-vm has moved

Jam’s VM integrations now live in [ekmett/jam](https://github.com/ekmett/jam),
alongside the collector they use. HotSpot, GraalVM and SubstrateVM support are
under [`vm/`](https://github.com/ekmett/jam/tree/main/vm). Development continues
there.

See the [build guide](https://github.com/ekmett/jam/blob/main/docs/vm/build.md)
and [documentation](https://ekmett.github.io/jam/). Please send new issues and
pull requests to [ekmett/jam](https://github.com/ekmett/jam).

The last independent version is preserved on
[`final-independent-release`](https://github.com/ekmett/jam-vm/tree/final-independent-release)
at [`97a10c1`](https://github.com/ekmett/jam-vm/commit/97a10c1d8ba9aa87f1116143c7edcb7c4c4eed27).
Its full history has also been merged into Jam. Existing commit links remain
valid.
